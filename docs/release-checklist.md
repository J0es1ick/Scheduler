# Контрольный список публичного релиза

1. Перевыпустить токен Telegram через BotFather и заменить `BOT_TOKEN`.
2. Выполнить `scripts/rotate-local-secrets.ps1 -RotateDatabasePassword` на запущенной локальной БД.
3. Убедиться, что `.env` отсутствует в Git и истории: `git log --all -- .env` не должен возвращать строки.
4. Оставить `ADMIN_ACCESS_LOGIN_ENABLED=false` и `ADMIN_COOKIE_SECURE=true`.
5. Настроить `ADMIN_TRUSTED_PROXY_CIDRS` только для фактического обратного прокси.
6. Убедиться, что CI из чистого checkout собрал обе веб-части и выполнил Go race/vet,
   проверку и сборку веб-интерфейсов, Playwright и интеграционные тесты PostgreSQL.
7. Собрать образ Docker и дождаться состояния `healthy` у postgres, bot, admin, site и backup.
8. Выполнить `scripts/verify-backup.ps1` и сохранить внешнюю резервную копию.
9. Проверить `/privacy`, `/my_data`, `/delete_me`, `/help`, `/metrics`, `/quiet_hours`, встроенный режим
   администратора и Mini App. В BotFather должен быть включён `/setinline`.
10. Создавать исходный архив только через `scripts/package-source.ps1`; скрипт включает лишь файлы Git.
11. Проверить, что `web/site/public/scheduler-social-preview.png`, README и документы из `docs`
    присутствуют в релизном коммите.
12. Включить защиту основной ветки и запретить слияние без успешных заданий `Secret scan`,
    `Go checks`, обеих `Web`-проверок, `Admin E2E` и `Migrations, Compose and restore smoke`.
13. Проверить все три пути интеграции: управляемый парсер, получение JSON и внешний коннектор с отправкой данных. Для каждого пройти
    `draft → testing → pending_review`, открыть тестовый снимок в «Источниках», опубликовать его и только затем
    активировать интеграцию. Управляемый парсер не должен требовать отдельного контейнера или закрытого ключа.
14. Убедиться, что публичный `/api/ready` не раскрывает операционные детали, а `/metrics` без
    отдельного токена доступа отвечает отказом.

CI повторяет поиск секретов, Go race/vet, проверку и сборку веб-интерфейсов, браузерные тесты, чистые миграции,
проверочный запуск Docker Compose и восстановление резервной копии.
